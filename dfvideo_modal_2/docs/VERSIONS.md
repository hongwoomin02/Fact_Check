## 4. 응답시간 측정 결과

동일한 FaceFusion 샘플 영상으로 측정하였다.

| 조건 | 횟수 | 클라이언트 중앙값 | 서버 내부 중앙값 |
|---|---:|---:|---:|
| Warm | 5 | 15.164초 | 4.495초 |
| Cold | 3 | 46.785초 | 18.071초 |
| Health-Cold | 3 | 28.647초 | 18.294초 |

Health-Cold의 /health 요청시간을 합산한 중앙값은 47.970초이다.

전체 11회에서 HTTP 200 응답을 확인하였으며, 동일 영상에 대해 FAKE 판정 및 video_margin -6.1898이 반복 관측되었다.

Cold 측정 당시 컨테이너가 실제로 0개였는지는 매회 확인하지 않았으므로 콜드 스타트의 정확한 지연 크기로 일반화하지 않는다.

## 5. 예외 처리 검증

| 테스트 | 확인 결과 |
|---|---|
| 얼굴 없는 영상 | UNKNOWN, 얼굴 검출 0/10 |
| 영상이 아닌 파일 | 영상 열기 오류 반환 |
| 손상된 영상 | 영상 열기 오류 반환 |
| 클라이언트 5초 제한 | curl 28, 5초 경과 후 요청 중단 |

브라우저에서 첫 세 가지 테스트의 응답을 확인하였다. 클라이언트 시간 제한은 curl로 검증했으며, 브라우저 자체의 시간 초과 안내는 아직 검증하지 않았다.

## 6. 재현성 관련 주의사항

본 문서의 SHA-256은 2026-10-12에 로컬 프로젝트에서 계산한 값이다. 배포 환경에 실제 포함된 파일과 동일한지는 별도 검증이 필요하다.

가중치 구성과 실제 로딩 조합은 manifest.json 및 추론 코드를 기준으로 추가 확인한다.

본 실험은 제한된 샘플과 반복 횟수에 대한 검증이며, 새로운 영상에 대한 일반화 성능이나 운영 부하 성능을 보장하지 않는다.
